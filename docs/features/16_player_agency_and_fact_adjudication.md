# 玩家行动权与事实裁定

## 问题证据

2026-08-18 的“现实世界”真实存档暴露出连续错误：警方先在玩家住处没有搜到球状闪电技术，模型便把“本次没有找到”升级成“玩家绝对没有相关科技”；之后即使玩家让战甲实际出现，并明确纠正“护盾不会被现有科技击穿”，模型仍引用自己先前写出的否定结论，把玩家后续释放球状闪电连续改写为虚张声势、幻觉和失败。错误正文又进入未来推演、状态与偏好证据，形成自我强化。

根因不是单次文风偏差，而是旧协议只有“符合事实”，没有定义谁有权建立哪类事实，也没有让未来推演把行动裁定结构化交给正文。

## 权限边界

1. 玩家决定玩家角色的意图、对白、思想和主动动作。
2. 玩家明确补充的自身背景、能力、持有物和括号纠错默认有效；只有明确的世界书绝对规则或锁定硬条件可以拒绝，且必须引用依据。
3. NPC 的意愿和独立行动不由玩家决定。
4. 攻击命中、敌人死亡、设施摧毁等外部结果仍由规则、状态和随机未来裁定。
5. 混合句拆开处理：玩家能够发射某能力，不等于玩家能单方面决定所有外部后果；但系统也不能通过否定能力来逃避裁定后果。
6. 玩家当前纠错优先于模型此前无依据添加的内容；世界书绝对规则仍高于临时纠错。

## 开放世界证据原则

模型不得采用“没有在当前上下文中出现，所以不存在”的封闭世界假设。必须区分：

- **观察事实**：警方在玩家住处的本次搜查没有找到设备。
- **角色认知**：警方因此更倾向于认为玩家在虚张声势。
- **客观结论**：设备在世界上不存在。前两项不能直接推出这一项。
- **仍开放的解释**：设备可能位于另一处仓库、车间、秘密空间、他人手中，或使用了当前世界允许但尚未揭示的隐藏方式。

负面证据可以降低某个解释的权重，却不能自动生成绝对否定。只有以下情况才能形成“明确不存在”的锁定事实：

1. 世界书绝对规则明确排除了该能力或事物；
2. 玩家以作者身份明确声明它不存在；
3. 故事已经完成覆盖相关可能性的充分验证，并且该验证范围本身可信；
4. 玩家接受了一个以“不存在”为核心、且界面已明确展示的正式裁定。

“现实世界”概述只提供默认规律，不意味着玩家不能通过明确输入引入超出现实科技的个人设定；否则任何超常故事都会在第一次现实检验时被模型擅自封死。

## 玩家输入的三种语义层

同一句“我有球状闪电”可能处于不同层级，不能一概当作客观事实或一概当作谎言：

1. **角色台词**：`“我有球状闪电。”` 只确定角色确实说了这句话；内容真假仍可未知，NPC 可以怀疑。
2. **玩家动作**：`我拿出/启动/发射球状闪电装置。` 默认确定玩家执行了该动作，并可建立支撑动作所必需的玩家侧事实；外部破坏效果仍可裁定。
3. **作者式补充或纠错**：`（设备其实藏在另一处仓库）`、`（护盾不会被现有武器击穿）`。它不是角色内心或台词，而是玩家对游戏现实的直接补充，默认覆盖模型无依据的旧推断。

需要避免另一个极端：玩家不能用普通动作句静默控制 NPC 意志、幕后真相或所有外部结果。若作者式补充直接推翻已经由玩家确认的世界书绝对规则或正式裁定，应提示这是“修改既有事实/回溯”，而不是悄悄改写。

## 待确认的默认创作权

玩家能否在遇到困难后随时新增“别处仓库、空间收纳、备用装置”等隐藏事实，会直接影响玩法是自由协作叙事还是带约束的 RPG。当前建议的默认折中是：

- 与已观察事实兼容的隐藏补充直接接受，例如“设备不在家，而在另一处仓库”。
- 引入新的能力体系但不推翻既有结果时接受，并明确记录为本回合新增的玩家设定，例如首次提出空间收纳。
- 想让新增设定反向取消已经发生的失败结果时，进入显式纠错/回溯流程。
- 未来可以提供“自由创作 / 平衡冒险”规则预设，但首版不为此增加复杂设置。

## 双阶段协议

未来推演返回 `action_adjudication`：

- `accepted_facts`：正文必须保留的行动、玩家自身事实和纠错。
- `contested_outcomes`：真正需要候选与随机处理的外部结果。
- `rejected_claims`：确实违反硬条件的部分及明确依据。

候选从 `accepted_facts` 已经发生之后开始分化。正文同时读取结构化裁定和被选中的未来，只负责呈现结果，不能再次否认已接受事实或替玩家追加重大决定。

首版不增加第三次 LLM 请求；裁定与未来候选由现有未来推演同一次 JSON 完成。字段缺失时后端降级为空结构，兼容旧模型响应和测试服务。

## 与偏好和时间线的关系

- 只有玩家真实输入和经过裁定的行为可以成为偏好证据；模型错误解释出的“玩家说谎、精神崩溃”等内容不能反向定义玩家。
- 结算模型只能用 `source_quote` 逐字指向本回合玩家输入；后端验证原文存在后，自己生成中性摘要并将单回合证据固定为 weak。模型自行撰写但无法回溯原文的证据直接丢弃。
- 未来的时间线节点应保存 `action_adjudication`，微调重演才能锁定“哪些事实不变、哪些结果重算”。
- 玩家纠错如果需要跨回合长期存在，后续应进入局内事实覆盖层；首版先通过当前输入、裁定和成功正文形成连续上下文，不直接自动修改世界书。

## 验收

1. 输入“我发射球状闪电摧毁囚车”且能力已建立时，至少把“成功发射”列入 accepted；只能裁定囚车是否摧毁。
2. 玩家用括号纠正模型此前无依据写出的能力失败时，候选不得继续以旧错误为硬事实。
3. 玩家命令独立 NPC 立刻投降时，NPC 意愿进入 contested，而不是被无条件接受。
4. 正文不得新增玩家投降、逃跑、羞愧、崩溃或攻击等重大决定。
5. 日志显示 accepted、contested 和 rejected，拒绝项必须有具体依据。
6. “某地点没搜到设备”只能写成观察事实和 NPC 认知，不能写成全世界不存在；玩家随后说明另一处仓库时必须保持兼容。
