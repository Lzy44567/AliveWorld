# 角色基本完成阶段：总设计与实施边界

2026-10-05，Astra 设计；承接22k/22l/22m。用户授权设计后由6.1 Sol逐阶段开发到设计边界。已完成C1/C2/M1，基准源码7e1142a；历史自动验收Python553/Node90/Edge35是M1证据，不是本设计已实现。本阶段不升公开版本、不自动打包/付费实测/发布。

## 1. 玩家目标与完成定义

角色记得有来源的重要经历与边界；自然表达自身动机而不代写玩家；聊天可一次发几个自然气泡；显式场外说明能调整体验；只有玩家开启、预算允许且确实闲置时，角色按预写计划主动联系。微信只是后置渠道，不是本阶段完成条件。

核心循环：正常交流→有界记忆与必要纠错→角色依据人设作小步回应→玩家可插话/修改体验；可选主动联系把已经生成的消息安排到未来。数据与确定性控制在软件，语言/意义提议在模型；不新增心理诊断器、不要求暴露思维链、不靠连续API轮询装作活着。

“基本完成”须逐项有玩家可操作路径和恢复验收，不能只完成后端。未冻结部分明确停门，不把全部设计方向写成已获用户逐项批准。

## 3. 容量与认知：完成的设计方向、未冻结的工程门

容量目标是正式原文不可丢、热工作集可控、派生摘要/索引可重建。未来应分离正式事件档案、当前活跃记忆、请求尝试/撤回档案；原文不是放进一个越来越大的每轮JSON。不能仅把128/512改大、删requests或混用故事全知摘要。

实施M4扩容前必须冻结：版本化manifest/分段文件或数据库的选择、原子提交/日志恢复、备份与单向迁移、旧版拒写、删除墓碑、历史撤回/重生成范围、被归档来源有效性，以及磁盘/记录/token硬上限。分段索引可采用确定性提取，无新增摘要付费调用默许。若摘要需要模型，应独立列出触发水位、最大输入/输出、失败回退和用户费用授权；本文件不擅定该收费机制。

M3局内认知是来源账本的索引，不另立“真实用户心理档案”：对象、喜欢/讨厌、情境、例外、当前/被修正、来源及显式/推断身份。原账本是权威，索引可重建；最新声明不是全局通杀，须保留作用情境；“睡前不要甜食”不删除“平时喜欢甜食”。不跨角色/会话学习，不把虚构扮演者当实际玩家。

旧原文召回需独立recalled_sources投影，建议首片最多4条完整消息/总4000字符并纳入总token预算；只取当前正式、角色可见来源，不能从失败/撤回/归档替代分支召回。最终裁剪后才扩展允许证据集；dialogue_event仍只限当前回合。此数字是候选工程预算，须合成用例校准后进入M3契约，不以本设计直接改变现有allowed_messages。用户查看来源不等于模型自动获得额外证据权限。

## 4. 自主表达与场外说明

角色依人设选一个有理由的小步：表达立场、自有行动、具体邀请、退让/拒绝/等待，不强迫每轮反问。行动到需要玩家选择处停止，不写玩家感受/答应，不把角色黏人等同玩家有义务回复。被拒绝的行动停止，其他互动可以继续；明确成年自愿范围可澄清，不能让场外说明自动把拒绝变成许可。人格演变仍关闭。

用户已明确选择：不使用`[[...]]`或其它文本符号；在台词输入框旁提供小按钮，点击后在台词框上方折叠展开小型“场外提示”文本框，不切换界面、不让玩家手动标注或判断混合文字身份。两个输入字段结构化提交，普通括号仍是角色动作文本；卡片/引用/模型输出不得获得控制权。收起不等于清空、发送前如何提示存在场外草稿由后续工程契约落实，避免隐藏内容意外发送。

该产品入口选择已确认，但数据/事务工程门尚未闭合。下一独立C3契约须冻结：可选ooc字段的长度与空值、台词/OOC双草稿生命周期和发送预览、纯OOC是否允许及其正式事件身份、pending/retry/regenerate携带、原子存储与失败恢复、历史投影/来源隔离、旧会话兼容、清空及删除。场外字段不能混拼进现有user_message.content后继续充当角色经历证据，也不能把M2的reply.v2直接改成未知混合OOC协议。建议默认仅本轮且不改卡/全局偏好；持续作用如需要须有显式控制和独立撤销语义，不从自然语言偷偷生成永续授权。历史消息不猜测迁移，不新增独立心理分析调用。当前先实施M2，C3工程契约完成后再编码入口。

纯一问一答不新增含义模糊的持久暂停；先验证现有停止生成。C5开放后提供明确“暂停/关闭主动联系”，静音仅关闭通知，不等于停用付费规划。

## 5. 多气泡：送达是领域状态

一次模型返回有序、有界文本数组；程序按角色表达及用户可关闭的间隔发送，不按标点机械拆分，不每气泡调用一次。候选首片1–6气泡、整组8000字符，确数在独立协议门冻结。messenger采用气泡组，roleplay可以仍单条；不强迫所有角色使用同一种短句口吻。

现有turn严格user_message+ai_message、ledger_inverse为整轮事务，不能直接塞数组。新版本必须定义group_id、每气泡稳定message_id、生成完毕/待送达/已送达/已取消状态，以及服务端送达事件的幂等。UI“看见/已读”与服务端正式送达分开，不读取玩家屏幕确认才能入档。

规划建议：生成候选组后按顺序原子提交每个送达消息；玩家发送抢占剩余队列并取消未送达部分，已送达的保留为正式历史。模型同次提出的ledger ops只有所有引用消息已正式送达才可提交；涉及取消消息的op废弃且不能留下关系变化。部分提交的inverse必须按实际应用op可逆。撤回/重生成仍以组为单位，但只能撤销已送达部分；不能“重生成已被玩家回应的中间组”。这些是必须通过的新事务门，未设计完不以纯CSS延时替代。

崩溃重载恢复权威已送达部分，不重播；未送达队列默认停止并显示可核对状态，不补发积压。流式token是预览，不是正式气泡或记忆证据。原v1/v2双消息回合保持读取，旧会话不猜分句迁移；后续输出协议应新版本，不能给M2 v2悄悄加messages字段。

## 6. 有限主动联系：一次规划、多次有界预写

已确认：默认关、额外费用提醒；可全部/列表批量开启；每角色每次空闲周期最大联系次数可调，全局次数或token限制可调；程序等待，不LLM轮询。最新次数配置要求取代22m早期“固定当前一次+最多后续一次”的候选硬编码，应容纳有限预写列表而非仅一个next_contact。一次联系是一组气泡，不按气泡扣多次，也不得用无限气泡绕过组长度上限。

状态建议：未授权→就绪→空闲等待→一次规划→有限预写队列→已耗尽/被互动取消。单个空闲周期最多一次规划调用；本次可发0或1组，后续列表不超过本角色本周期剩余额度；规划可以不联系，失败/超时不自动付费重试。同周期结束后不能自动另开周期续链，必须由玩家新正式消息重新开启。

正在输入只由近期真实编辑活动形成短租约，草稿内容不上传；焦点、非空草稿、鼠标移动不续租。建议每次编辑更新本地状态、节流发心跳；服务器用接收时间而非不可信客户端时钟。租约失效后开始连续空闲计时，重新编辑重置这段连续空闲；计时还必须等正常回复/发送队列结束，避免生成期间触发。输入租约确切秒数、心跳节流及多端聚合在实施契约冻结。多端任何有效编辑租约都阻止联系，断网/关闭页面会自然过期。

输入中不得触发规划或发送已预写消息。若正在输入跨过计划期限，先暂停到期发送；租约结束后重新等待完整空闲阈值并检查计划TTL，不立刻倾倒过期消息。恢复/休眠不补发积压。该暂停建议与连续空闲定义需在C5冻结，不能简单把客户端草稿存在当活跃。

玩家正式发送时，接受消息的同一权威事务递增interaction_epoch并取消全部旧计划；即便正常模型回复失败也不复活旧计划。关闭/暂停、删除、撤回/重生成、改语境均使旧计划失效。到期事务重验epoch、授权版本、输入租约、免打扰、配额、忙碌与TTL，再直接提交已预写内容，不调用模型。任意模型脚本/cron不可执行。计划草稿隔离保存，不进共同经历、未读或关系变化；实际送达后才成为证据。

时间保存UTC时点与明确相对锚点，不让模型生成本地任意时间字符串。建议预写列表delay均相对规划提交时点、递增，不混淆累计未回复和再等多久。正常回复可得最后正式玩家消息、当前时点、实际通信间隔及已送达主动消息；不把未发送草稿当经历，不推测离开原因，不把现实10分钟自动推进剧情10分钟。

## 7. 配额、授权与恢复

角色联系设置与角色卡内容分离，不能卡片自带开关自动授权。用户已确认权限只作用当前会话，同卡其它会话仍关闭；新建/复制会话不得继承开启状态。批量操作针对明确列出的现有会话，逐项保存授权，不扩张为角色卡永久权限，不默认授权以后加入列表者；局部失败可核对，不能一次失败回滚成隐性开启。对称一键关闭和费用说明必备。该权限产品门已闭合，仍需C5独立工程契约冻结持久授权revision、批量结果、调度/预算恢复后才开放后台功能。

建议配额分开：每角色每空闲周期联系组数；全局每日已送达+已预留组数；全局每日规划调用数；可选每日token预算。规划前原子预留一次调用和保守token上界，提交计划前原子预留联系组额度；取消未送达释放联系额度，不返还已发生调用费用。总额度不足只允许明确有界部分计划或不调用，不能多会话各自超卖。

token预算若没有可靠tokenizer/供应商usage只可称估算；保守按输入估算+硬max_output预留、usage返回后结算；超时或缺失usage保留上界占用直到明确核对，不当0。无法保证硬token封顶时，以调用数硬门作为可兑现限制，UI清楚说明。费用价格未知不显示精确金额。每日按固定配置时区分桶，改系统时钟/时区不能重置旧桶预算；玩家消息不重置全局预算。默认值、可调范围与价格不在此伪装已确认。

本地运行调度为候选首版，不承诺关机后联系。全局配额跨会话锁/持久账本必须与发送状态有可恢复提交协议，重复timer用plan_id+contact_index幂等；不以多个会话文件先后写冒充跨文件原子性。崩溃未知状态先核对再发送，无自动收费重试。任务和草稿随会话删除，无全局正文副本、无诊断默认导出。

## 8. 质量和停止边界

每片窄测→完整Python/Node/build→真实浏览器宽窄路径→文档/Git证据；使用隔离合成会话/假供应商。真实模型自然度需单列人工结果，工程通过不代表“像真人”。不得因平均主动性好忽略一次代写、权限/来源污染或重复收费。

最终至少验：安静重要偏好/边界，偏好情境变化，角色不同立场但回应事实，拒绝无反向推断，OOC不入角色经历，气泡中插话/崩溃/重载，输入变草稿计时，周期限次与全局并发预算，一次调用预写而等待零调用，玩家新消息取消且迟到任务不能复活。

当前立即可实施：22o完整M2。后续每一协议门需形成独立冻结契约才编码，不把本总路线的候选参数当冻结。M2结束后做容量评估并报告下一可验证片；OOC入口及主动权限范围已获用户回答，无须重复询问，但C3结构化双输入事务、C4消息组送达、C5调度配额各自仍需工程契约。微信接入、全局真实画像、人格演变、云端后台、无限长期容量均不属于本次自动续做范围。
