# 可选数值规则与隐藏身份

日期：2026-10-12。状态：用户方向已确认，以下产品机制为设计候选，未编码。

## 已确认方向

- 不要求所有世界数值化，避免同质化；提供“启用数值规则”类开关。
- 开启后世界书工坊加入设计数值的指导提示词，通过少量询问与自行推导，产出相对通用、可扩展的规则，不枚举全部人物和物品。
- 普通人物可在普通人属性范围生成参数，但必须考虑隐藏强者，不能将所有貌似路人都永久判为普通人。保留合理反转与小说感。

## 模式与入口建议

- 默认自由叙事，不生成一套隐藏通用属性表；可有明确资源数值如金币/弹药，不等于启用了全面数值判定。数值规则默认关闭为建议，世界包可提供推荐配置。
- 数值、骰子和未来随机是不同能力：无属性表也能抽未来；数值可采用确定性门槛而不投骰子；需要骰子时才使用对应规则。不增加三个并列必填开关，普通界面显示“判定方式：自由叙事/数值规则”，骰子在规则内选择。
- 世界书工坊中开启数值设计进入规则草稿，不立即改变已运行故事。创建故事载入已发布的规则版本；中途切换需展示影响并处理已有角色尺度，不能重抽现有属性。开关关闭保留原数据和版本，不删除成长。
- 工坊指导仅在设计数值时注入；故事只读精简规则和本轮相关参数，正文收到结算结果，不携带整篇设计教程。

## 工坊产物与作者体验

先问世界力量尺度、主要玩法、想要的随机程度；提供可选方向及少量例子，不要求作者手填公式。未明确处提出可修改建议，不暗中冻结。

生成规则包括：必要属性及含义、普通/熟练/强者等参照、取值范围与分布、成长与上限/境界差异、门槛/对抗/工具环境修正、未知对象生成办法。不同题材可用完全不同维度，不强制六维属性或统一D20。

普通参数由程序按角色类别和背景约束生成，相关属性不必逐项独立均匀随机；仅在身份或判定实际需要时生成并保存。情境选择、背景解释由AI负责，重复相遇不重抽。无依据的真实身份保留未定，不将玩家看到的“普通”当客观普通。

提供普通人/高手、同级对抗、难度边界等少量可读例子供作者判断尺度；规则改动显示例子结果变化，避免靠大量枚举调数值。

## 隐藏身份与反转建议

核心分开实际身份/能力、对外表现、各角色知道的信息。玩家只看到普通，不意味着后台必须是普通；未定身份也不等于允许无限事后改写。

三类来源：作者预设隐藏身份；世界人口/地点/组织规则允许的稀有身份；自然剧情引出的身份补充。AI不每次遇见路人都询问“是否隐藏强者”，不单独增加模型调用。

- 作者已设定身份就沿用。新重要人物在本来发生的未来推演/创作中，可以提出有世界和场景依据的身份候选；选定后记录并保持，揭露可以延后。普通无关路人不预建复杂档案。
- 已有明确真实属性或经可靠证据确认的能力，不得为了压制玩家突然改成强者。原先只是伪装表现则可揭露；此前事件的解释必须一致。
- 身份在决定行动成败前确定，不能在骰子失败/成功后为预定剧情改属性。若暂不生成隐藏身份，不预抽一套假的“真实普通属性”；保留可见观察即可。
- 反转须受世界可信度约束；不是每隔N回合强制出现，也不是玩家顺利就升级敌人。可以通过动机、误会、信息差、资源代价制造变化，无须全靠更强人物。
- 暂不增加玩家“隐藏强者概率”滑块。候选使用世界书/创作偏好的反转风格指导、已有剧情节奏信息；如确需概率，由该世界规则定义，不写全局固定百分比。
- 遇到原稿未定、但已有事实约束的身份补充，应检查其能否解释旧行为，不能将“可以补全设定”当作推翻既定结果权限。

## 验收例与待定范围

自由叙事世界不会因运行而偷偷填属性；开启工坊指导不立即重写旧存档；普通人物重访数值不漂移；伪装强者有稳定真实身份，揭露不改变旧结算；已有明确普通人的战败不触发临时升格；各题材产出的属性维度可不同。

后续决定：世界包规则版本切换与迁移UI、规则生成模板首批覆盖范围、未定身份允许在哪些阶段补全。公式/工程字段在产品例子通过后细化。
