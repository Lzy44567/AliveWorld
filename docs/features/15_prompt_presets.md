# 模型适配与内容提示词预设

## 问题

不同 OpenAI-compatible 模型对 system 消息、JSON mode、assistant prefill、stop、温度和长提示词的遵循能力不同。玩家也可能希望附加自定义创作约束，俗称“预设”或“破限”。这两类需求不能直接拼进 API Key 配置，也不能把一个正文预设无条件发送给记忆、Overseer 和工坊。

## 两类预设

### 模型适配预设

面向协议兼容和输出稳定性，可包含：

- system 前置/后置兼容说明；
- user 前置/后置格式说明；
- JSON 输出补充约束；
- 可选 assistant prefill；
- stop sequences、温度、最大输出等受支持参数覆盖；
- 模型/服务商标签和已验证任务范围。

它默认绑定连接档案，也可被具体任务路由覆盖。参数必须经过协议白名单，不能把任意 JSON 直接透传给 SDK。

### 内容提示词预设

面向创作风格和内容边界，是可复用资产，可选择全局默认或本局覆盖，并按正文、工坊、生图提示词等任务启用。玩家自定义的“破限提示词”属于此类普通文本；AliveWorld 只负责透明注入和开关，不承诺绕过供应商审核，也不伪装审核错误。

## 注入协议

预设由独立 `PromptComposer` 生成消息列表，而不是在 `AIEngine` 内继续拼接字符串。首版候选槽位：

1. `system_prefix`
2. AliveWorld 核心系统提示词（不可被预设覆盖）
3. `system_suffix`
4. AliveWorld 任务上下文
5. `user_prefix`
6. 当前用户/任务输入
7. `user_suffix`
8. 可选 `assistant_prefill`

每次 LLM trace 记录预设 ID、版本、任务和注入槽位，但默认日志摘要不复制整段敏感预设。关闭预设后，提示词、prefill 和参数覆盖都必须停止发送。

## UI 与资产边界

- 普通设置只显示“当前模型预设：默认/名称”和启停开关。
- 高级设置提供预设管理、任务作用域、注入预览和 token 估算。
- API Key、模型连接与预设独立保存；删除连接不删除预设。
- 世界包可以声明推荐内容预设，但导入时必须预览并由玩家选择，不能静默启用高影响提示词。
- 预设支持重命名、克隆、导入导出和重名检测；是否兼容 SillyTavern preset 需单独做字段映射报告。

## 开发顺序

1. P0：消息组装领域对象、任务作用域、启停与日志来源。
2. P0：正文 JSON、工坊和记忆的契约测试，证明预设不会破坏各自协议。
3. P1：管理 UI、克隆/导入导出、模型连接默认预设和任务覆盖。
4. P2：SillyTavern 预设兼容、服务商原生参数与社区分享。

在确定 assistant prefill 的跨服务商降级方式、内容预设的局内/全局优先级和世界包导入权限前，不直接实现自由消息数组编辑器。
