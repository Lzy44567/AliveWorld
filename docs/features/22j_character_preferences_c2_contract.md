## 数据、权限与恢复

使用extensions.character_preferences={enabled:boolean,include_sensitive:boolean}，缺失等于双关闭；严格白名单/类型，关闭主开关时同步撤销敏感授权。不全量迁移旧文件、不改schema；设置更新沿用修订CAS与忙碌保护，响应包含规范化设置，浏览器不承担真实授权。

普通启用不代表敏感授权；adult类或sensitive=true须额外开启。没有标记的非adult旧条目暂视普通，不能声称程序可以识别所有自由文本隐私；疑似私密内容请先在偏好卡正确分类标记。来源/evidence/assessments/推断心理/路径/密钥不投影；只投影category/polarity/statement，无原始ID，最多20条、陈述正文累计2400Unicode字符、每条最多400字符，整条跳过而非切尾。JSON标签等额外占用由实际请求总预算计算。稳定按类别与原书顺序，重复条目去重。

请求开始后偏好投影冻结在内存job，同一流式/非流式过程不受全局偏好修改影响。程序不直接把投影副本写入pending/retry/历史/账本/日志；模型正式回复仍正常保存，不能保证它绝不复述偏好文本，也不能控制供应商侧的数据保留。已接受请求无法从远端召回。会话忙碌时不可改设置。失败、取消、进程恢复后的显式重试是新attempt，重新检查当前会话授权/全局类别与偏好；重生成也重新取材。幂等重放同action不重复读取或调用。此策略不承诺跨attempt提示词完全相同，但避免撤销授权后重放旧敏感快照。

预算优先整条移除偏好，再维持C1既有裁剪顺序；偏好不挤掉必需角色/公理/当前输入，也不扩张消息证据集合。页面说明只读/分类/敏感边界，无每回合额外模型调用。
