# 故事与工坊流式输出

日期：2026-10-03。用户已确认先覆盖现有故事正文和工坊对话，再复用到角色模式。本切片不实现角色引擎，不把22b角色专属会话协议移植到旧故事。

## 玩家目标与边界

尽早看到模型正在生成的正文/工坊答复，避免完整生成期间只有等待。流式并不缩短模型总推理时间；未来推演、状态结算与存盘仍需完成。

- 故事普通行动、重试、重掷：只增量显示结算的`story_text`。未来候选、暗流、设定捕获不直接流到界面。
- 世界书、偏好、角色/文风/实体工坊：只显示既有答复中的理解、设计依据、结论等允许字段。operations、状态修改、建议数组、隐藏推理不能作为临时正文显示。
- 新流式路径与原JSON路径并存。界面可关闭流式以兼容服务；失败不自动切换路径或重复收费。流式单次模型调用禁止空返回自动重试与SDK重试；原非流式行为不顺手改写。
- 临时预览标“生成中/未保存”；完整结果经现有验证、事务与保存后才替换正式记录和状态。结束异常/非法JSON/存盘失败清预览，不部分提交。

## 实施契约

- 在现有action/retry/reroll和三类工坊chat路径后追加`/stream`，请求体保持原结构；原端点不变。
- POST SSE事件`start`、`delta`（`{text}`）、`complete`（原端点最终payload）、`error`（安全message/code）。SSE EOF无complete为结果未确认，提示重新载入核对，不自动重发生成。
- 同一聚合原变更锁在工作线程中覆盖生成到保存，不能只锁住StreamingResponse创建；不同故事/工坊继续并发。前端reader/预览归发起context，不归组件生命周期，切换视图不abort。
- 累积raw JSON只用于原最终校验，增量词法识别白名单字符串并正确解码转义/Unicode；不正则截取，不把模型推理字段加入预览。
- 故事复用已有失败恢复与存盘后捕获。工坊在隔离副本生成/应用，保存成功才替换运行对象；存盘失败不保留半应用草稿或消息。
- 本切片不提供停止生成按钮或持久化流重放。浏览器真实断开后不再发送预览，已启动事务继续正常完成/失败；再次打开需载入权威记录。与22b未来角色断线取消契约不同，不宣称当前旧故事具备该能力。
- 队列与内容设边界，慢/断开消费者不能永远阻塞线程；不显示或记录新的内部思维链。供应商不支持stream需明确报错，由玩家自行关闭流式后重试。

## 优先级与验收

P1当前：传输/JSON增量抽取→故事/全部工坊事务接入→前端隔离预览→假HTTP/真实浏览器及旧功能回归。P2：停止按钮、持久化请求身份/重连事件、角色模式复用；后者应按其产品/工程设计实现，不靠本切片冒充完成。

必须验证：跨chunk转义/中文/emoji、嵌套同名键不泄漏、完整JSON独立校验；finish length/filter/异常失败；模型调用次数不增加；结果写失败无正式变化；同对象busy/不同对象并行；切换会话仍正确完成；临时预览出现于保存前且状态不提前刷新；关闭流式使用旧路径；终态缺失不自动调用模型。

测试仅使用隔离假API与合成资产；不读取游玩区、不调用收费模型、不升级版本或发布。实际完成数与命令在验收后写回，不预写通过结果。
