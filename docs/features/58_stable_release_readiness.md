# 58：1.6.0正式版收口

2026-11-11。承接用户“为什么持续dev、继续下一轮”授权；57/dev39已交付，不重开其功能。

## 目标与版本约定

下一交付候选为1.6.0-rc.1，不是立即宣布稳定。dev用于功能范围仍变化的开发版；rc用于本次范围冻结、只处理交付阻塞；正式1.6.0表示当前承诺范围通过验收，不代表全部设计灵感实现。正式版之后兼容修复使用1.6.x，新的完整功能组使用1.7.0等次版本；破坏兼容的变更单独评估。版本只在验收进入构建门时统一修改，不覆盖旧标签。

## 冻结范围与非目标

- 当前故事模式、独立角色聊天、五类工坊、资源/世界包、接口设置与Windows便携包更新。
- 不将群聊、任意历史节点分支树、自动生成完整小游戏、全面手机适配纳入1.6.0门槛；未实现能力不能在入口或介绍中承诺可用。
- 本轮不重构业务底座，不新增默认模型调用，不改变玩家数据所有权。

## 执行及验收

1. P1更新链：dev39→rc1→1.6.0排序与检测、正式渠道过滤、版本展示、发布说明、安装助手保留UserData；测试使用合成数据及假HTTP响应，真实发布附件最终另核对。
2. P1完整玩家路径：首次配置→创建/导入故事→生成→停止/失败恢复→存取/撤回；角色载入/消息/记忆授权；工坊讨论/部分审阅/发布/继续讨论。复用现有浏览器测试，缺失处补场景，不靠总测试数量推断覆盖。
3. P1交付审计：公开入口、帮助与实际能力一致；备份/覆盖更新失败可恢复，不上传日志/密钥/存档；旧dev39存档使用复制件验证，不碰游玩目录。
4. 完成代码和UI问题修复、全量回归、打包主EXE与助手、便携包结构/隐私/覆盖验收后发布rc。模型表现仍单独标记，不以假模型测试宣称文学质量保证。
5. 正式1.6.0门槛：上述证据全部完成且无已知P0/P1；rc实际游玩和更新验收反馈未发现阻塞。不得只改后缀即宣布正式，也不要求玩家无限期体验；需要用户参与时给出具体最短验收清单。
