# 故事人物提取与跨世界载入

日期：2026-10-12。状态：用户需求已确认，产品细节为候选；本轮不编码。

## 目标与已确认范围

玩家可将故事中的人物提取成角色卡，包括性格、记忆、言行习惯，带去其他世界。支持带记忆、仅人设两种使用方式；入口在提取或载入阶段均可，用户尚未限定具体位置。

## 建议流程

人物详情/局内卡的更多菜单→提取角色卡→工坊整理预览→保存全局新资产；不要求人物先成为暗流实体，不修改源人物或原存档。优先使用稳定身份及别名索引、局内记录和相关原文，不能仅靠同名文本搜索。

提取资料分为人物底稿（身份、性格、能力、表达/行为示例）与可选经历包（重要经历、关系、承诺、知识/信念）。局内短期情绪、伤势、当前地点默认不写成永久性格。模型提炼与原稿明确设定分别展示，不能把一次行为推断成终身特质。

建议提取时选择是否包含经历，载入时对包含经历的卡再次选择携带与否。同一资产可供两种玩法使用，未提取的经历无法凭空恢复。只带人设不自动重置为最初人物：默认保留提取时确认的人设与习惯，是否还原原始卡另做明确选项。

## 经历与跨世界语义

- 携带经历表示角色记得源世界发生的事，不表示这些事在目标世界也发生过。旧人物关系按身份映射，不把目标世界同名角色自动当老朋友。
- 只保留该角色知道/经历的内容；幕后秘密、其他人私有记忆、玩家个人偏好不自动携带。示例对话是表达参考，不默认为新会话发生过的事实。
- 原始证据留本地；用于分享的经历包默认整理为可读摘要并预览，原始聊天及来源隐私显式选择，不为溯源强制打包整份存档。
- 来源世界能力与目标世界规则冲突时呈现适配选择，不因为带了角色卡就改目标世界基础规则。保持角色能力原意、限制能力或转换为目标体系的具体默认仍待确认。
- 提取内容携带必要背景解释/依赖清单，避免必须导入整本源世界书才能理解角色；工坊可建议附带少量相关知识，需审阅。
- 角色进入新故事生成独立局内实例；新经历不自动反写全局卡或源存档。未来可再次提取新版本。

## UI与验收

默认预览人设，经历包独立折叠；两张清晰选项卡“仅人设／携带经历”，深层选项后置。原文证据按需展开，不一次展示全部账本字段。

验收样例：匿名路人后实名且多次互动，能提取为一个角色；带经历记得旧承诺但不认识新世界同名人；仅人设不引用旧游玩往事；源世界能力冲突提示适配；取消提取不修改原故事。
