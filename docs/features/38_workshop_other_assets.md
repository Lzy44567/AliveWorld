## A实现与边界

入口为原工坊对话提案区，不增加新页面。审阅单位是模型提出的一份连贯操作，不是任意拆分结构字段；模型应将可独立修改分开，互相依赖字段保留为一组。界面展示完整修改内容。

模型只提案；Python按ID选择并按原顺序应用，各领域继续负责字段权限与偏好规则。接受即玩家明确确认（含偏好启用或删除），只进入草稿，发布才生效。拒绝不改草稿，未选项保留。一次批选接受对应一次撤销；撤销不重新放回已审阅提案。

会话仍属于原资产路径/偏好会话；沿用保存格式，无迁移、无新增模型请求、不扩大敏感偏好读取范围。已发布会话只读。接口沿用会话锁、候选副本及成功存盘后提交，保存失败不半写，切换工坊不将结果写入其他会话。

验收：各类型部分接受/拒绝、剩余项持久化、撤销、过期ID、发布只读；真实HTTP保存失败不污染内存；前端构建及共享审阅浏览器回归。真实模型创作质量与功能测试分开。
