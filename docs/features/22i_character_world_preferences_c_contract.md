## C1确定性匹配与数据边界

继续使用创建时绑定的世界书快照，不读取当前可变全局书，不写卡片、账本或旧会话，不改会话schema。旧会话也按新请求规则匹配，但其历史/世界快照不迁移。

概述、公理、常驻/绝对规则维持必需集合。普通条目关键词范围为本次输入与最近最多4个正式回合的双方公开消息；历史窗口额外上限12000 Unicode字符，按完整消息从新到旧选取，不切断消息。本次输入独立必需，不受额外窗口上限截断。超大历史消息跳过，不能借由它扫描更早于4回合的内容。

仅选择对当前双方都公开的正式消息。预览、作者开场、角色示例、私有账本、失败输入、撤回/被替换归档、全历史和其他会话全部排除。重生成以撤出被替换回合后的工作快照取材；撤回后自然不再触发已撤销内容。

关键词沿用世界书的逗号分隔/大小写无关子串匹配，不新增语义模型或付费分析。复用关键词解析，不复用故事全知检索窗口。停用、待确认、待删除条目不参与；常驻/绝对规则不重复进入普通条目。

普通命中优先级：本次输入→最近正式回合→更早正式回合→书内顺序。无关键词重复计分/永久激活，最多16个普通条目。预算不足沿现有顺序整条移除低优先条目，再按原规则处理示例、历史及账本；不裁剪公理/常驻集合以冒充可发送。必需集合超限仍零调用。

绑定书属于作者世界语境，不等于角色亲历或全知。世界条目不获得可引用消息ID，不能伪造角色知识账本来源。引擎提示明确角色实际知情以资料与正式对话证据为准。本片不解析自由文本秘密，也不声称实现世界书条目级机密权限；创作者若把秘密混入公开概述，程序不能证明模型不会泄露。条目级作者/角色可见性需后续独立数据契约，不以关键词或敏感词猜测权限。

## C1可观察性、预算与生命周期

纯选择模块返回模型数据与独立安全报告；上下文构建器负责总预算，service负责把最终报告附加到accepted/最终结果，store按发起会话保存短期报告，单独UI组件显示。Workspace只组合，不承担检索和预算。

报告最多16项：条目ID、截短名称、命中来源（本次输入/近期聊天）、回合距离、计划是否发送；另有窗口/常驻数量、超16项数量和预算省略数量。无消息原文、命中关键词、私有记录、书全文、路径、配置或密钥。它不是角色记忆，不入模型提示、账本、会话存档或localStorage。

资料→世界书栏目解释真实触发范围，并可展开本次请求的匹配计划。没有请求时不猜测命中；禁用/未绑定无报告内容。停止或失败后可保留该请求的计划，但不标成已成功执行。离开/重载后不冒称从历史恢复报告。流式、非流式一致；切会话/后台完成只更新所属会话。

## C1验收与停止门

1. 本次/最近双方话题命中；四回合外、超窗口、私有消息、开场/示例/预览/归档均不命中。Unicode/大小写/逗号、常驻/停用/待确认/待删除、排序及16项稳定。
2. 预算整条省略与报告同步；报告无正文/关键词/秘密哨兵；引擎消息来源集合不扩权，必需超限零调用。构建前后会话字节不变。
3. 服务流式与非流式报告一致；两会话报告隔离；UI可展开、空态、预算说明、正常选择文本，不加逐条复制按钮。
