# 工坊创作与审阅交付

2026-10-17，依据30/31和已确认的逐条/勾选/全部操作。当前开发主线，非已完成声明。

## 玩家目标与范围

玩家在原工坊内选择喜欢的修改，未选方案仍保留；接受只写草稿，发布才改变目标资产。先世界书闭环，再创作目标持续参考，不扩大为跨资产世界包、融合、试演或全站UI重做。

## 实施顺序

1. P1编码：以现存operation_id选择proposed/pending；接受和拒绝均支持数组。按原方案顺序执行，同批全成或全败；未知/过时ID报错不静默跳过。复用既有会话锁、隔离副本保存事务及草稿撤销。
2. P1界面：原方案列表复用条目内容；单项按钮、勾选后批量工具条、全部操作。高影响项明确警示，人工点击接受即确认所选项；旧自动修改风险门不变。切换作品清空勾选，不跨作品操作。
3. P1提示词：保存与世界事实分离的创作目标，已有信息不反复询问，最多少量影响方向的问题；不增加额外模型调用。实施前核对现有存储和提示词分区。
4. 验收：部分接受/拒绝保留其余、失效目标批次不半写、撤销、重新载入、局内与全局隔离；假模型真HTTP及浏览器检查。模型创作质量单独标注。

## 数据与实现边界

审阅权属于玩家，模型只提出操作。Python验证引用与提交，Vue只管理选择与显示。拒绝不改世界书；接受按既有draft快照撤销，不承诺撤销恢复被拒绝的提案。发布和资产冲突检查沿原路径；不读取玩家数据、不新增付费测试、不自动升版本发布。
