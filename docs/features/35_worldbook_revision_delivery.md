# 世界书捕获与修订闭环：本轮实施

2026-10-14，P1核心功能。用户已授权继续完整板块；产品依据24，旧18/21仅作实现历史。当前不是整个世界知识系统交付。

## 最终玩家流程与范围

故事确认可复用设定→既有后台捕获→本局条目新增/修订/失效→轻提示或逐条人工处理→后续正文读取有效内容→撤回/重生成恢复对应世界书。无世界书仍用已有自动书，不更改全局资源。已有逐条审阅入口复用，增加批量处理与清楚的处理状态，不建设第二工坊。

本轮不做多书融合、公理/概述修改、任意自然语言条件自动执行、主动新场景扩写、完整实体资料或全新分支UI。保留这些设计，不能称24全部完成。

## 职责与数据

- AI：识别首次发现或真正规则变动，给出正文证据、目标条目、内容与范围；同一次正文给短信号，只有需要整理才额外捕获。通用提示不依赖题材口令。
- Python：分配变更ID；准确目标引用；记录源回合指纹、条目ID、前后内容、处理状态；执行修订与失效、撤回恢复和迟到结果拒绝。仅条目变化，不新增万能规则引擎。
- UI：复用局内世界书编辑/审阅，显示自动写入或待审，而不是混为一谈；逐条/批量接受拒绝，废止保留历史。代码模块各自拥有规则、HTTP映射、UI行为。
- 修订记录放当前局内书的capture_history，与条目同一次原子保存，不建独立数据库。沿用源回合指纹（消息ID＋内容），不能只用回合数字。旧书没有记录时不猜历史、不追溯合并。

## 回退及并发约定

捕获提交仍复核源回合及目标修订，复用故事变更锁和文件原子替换。撤回/重生成逆序检查无效源记录；当前条目等于该记录after时恢复before，新增移出活动内容。若被玩家独立修改，则保留人工版本，记录detached而非静默覆盖。历史记录不物理删除。

工程简化：撤回不同时重写一批书文件，而是以当前故事有效源回合投影条目。ContextManager与局内资产读取复用同一投影，重生成使用回退后的运行时回合，不错误读取磁盘上的旧未来；下次真正编辑/捕获时再把投影和修订状态一起原子保存。这避免跨多文件回滚事务，失败正文不会改变有效源。磁盘书保留历史，不代表被撤回内容仍进入模型。后续详细测试需覆盖确认后的候选、手改后再自动修改、所有局内读写入口均用同一投影。

## 顺序与验收

1. 修订记录纯逻辑：新增/修改/废止前后镜像、相同回合号不同身份、人工修改保留、重复回退幂等。
2. 捕获/存取/撤回/重生成接线：源与书原子性、失效任务不能复活、失败保留原文、全局模板不变。
3. 通用捕获与自动/人工规则；既有审阅入口接修订并增加批量操作和提示。精确恢复用历史原文，不让AI凭空补原规则。
4. 假模型真实HTTP＋浏览器从空故事到新增/修改/废止/审阅/撤回，Python与前端回归、截图、分类日志、本地提交。

阶段1是基础，不代表玩家功能交付；目的模式保持到以上闭环达成或发现真正未决产品边界。不升级版本/打包/推送，不读取玩家存档。

## 阶段2实施约定

正文信号add同时涵盖首次确认可复用既有知识；无机制的提名不捕获。自动update/retire必须引用准确目标以及零起始event_index，有持久、非个体例外的已确认信号，低风险高置信且关闭人工审阅；旧兼容输出缺引用仍待确认。已有待确认条目不能被当作正式规则改写。同批一个目标只处理一次，不覆盖自身新结果。retire停用并保留内容/身份，不物理删除。

restore涉及恢复哪份历史，当前仍进入待审，不凭AI文本假称精确还原；纯撤回由修订镜像恢复已接通。条件自动失效仍在本板块外。自动修改的范围和风险判断不等于语义绝对正确。

## 人工审阅（阶段3已接界面，整板块审计继续）

独立worldbook_review对投影副本逐项/批量处理。接受修改保持目标ID；废止停用保留原文；接受/拒绝另记决定，相关条目差分继承原源回合，因此撤回后不会复活被拒候选或保留已撤回修订。提案保存目标内容修订，接受前检查原条目没有另行修改；书级expected_revision保护打开面板之后的并发变化。单批失败不写部分结果。

API：POST /game/{session_id}/worldbooks/{asset_name}/review，decisions与expected_revision，复用故事/书写锁及原子存盘，返回最新书和edit_revision。现有局内编辑页已接逐条、勾选和全部接受/拒绝；操作立即保存。普通局内编辑保留服务端历史并检查revision。后台完成轻提示不展示私密设定全文，打开编辑页先刷新。待审条目明确标为尚未生效。

2026-10-15收尾审计：人工改过的候选在源回合撤回后保留，但不能再接受为原捕获结果，可拒绝清理；重生成请求不包含旧未来捕获内容。新增浏览器场景已通过自动新增/修改/废止/两次撤回/人工选中接受与全部拒绝。发现工坊局内读取仍是磁盘原文，必须继续接入有效投影及发布一致性后才能标整块完成。多书融合等原范围不变。
