## 冻结范围

- 顶部紧凑标题/状态/撤销发布/专注；不继续堆叠模式说明、目标与参考折叠框。
- 创作方式、目标、参考书、历史记忆和流式设置移至独立配置浮层。默认关闭，按需打开，浮层自身滚动、不参与中央高度分配；Esc先关闭浮层，不同时退出专注。关闭保留组件草稿，切换资产仍按原有会话边界。
- 输入前一行保留当前模式的配置入口、讨论/修改权限；定向改写有简短可见提示。输入区紧凑，完整长文本继续用已有展开编辑器。
- 建议在阅读流末尾，不随数量增多不断推高固定底栏。接受/拒绝保持方案末尾，发布/历史/停止重试机制不变。
- 不改API、模型提示词、数据结构或费用授权；UI临时开关不写玩家存档。不是全软件UI重构，不修改聊天模式。
