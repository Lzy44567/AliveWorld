# 47 世界书捕获结果与修订记录

2026-10-23，P1 玩家可见性闭环，依据24第三/四轮、35与46。目标dev.29实际打包发布。

## 玩家流程与范围

后台写入完成后显示聚合轻提示，告知世界书记录更新，点击可到右侧世界书的“修订记录”。默认只显示数量、目标书、源回合与状态；主动展开详情才读取并展示条目前后内容，并提示可能包含隐藏设定。待审项进入原书现有逐条/批量审阅，不造第二套审阅事务。

不新增模型调用，不改变捕获或审阅决定，不新增持久通知文件。暂不做逐条自动剧透提示、自动弹出审阅窗、AI重写、跨书移动、完整世界融合。历史记录是后台修订快照，不冒称当前条目仍与该快照相同。

## 实现职责与生命周期

- 领域：从既有capture_history、capture_reviews及有效回合投影构造只读列表。区分写入记录、待审、已接受/拒绝、撤回失效、人工修改保留。条目历史按源回合降序，同回合保留文件内修订顺序；不是跨文件精确时钟。
- API：局内身份由会话与文件目录决定，分页每次30项；默认不返回标题/正文/前后原文，显式details查询才返回。只读、不修改存档。
- UI：故事前台每5秒取摘要，隐藏页停止轮询，不调用LLM；首次进入只建立基线，不把旧记录刷成新通知。切故事隔离结果，异步旧响应不得串到新故事。新增ID聚合一次提示，撤回只更新历史状态。
- 通知：本浏览器内存记忆已看基线，重开不补旧消息；记录始终可手动打开。网络失败不反复toast，面板可刷新显示错误。多条提示合并，不展示可能剧透的条目名称。
- 记录入口在世界书本局面板，列表折叠、展开后分页；查看内容是显式玩家操作。跳转使用文件标识并读取原书最新版本，搜索过滤不得导致打开空编辑器。已删除书不伪造记录，书历史随书/存档删除。

## 验收与边界

纯投影覆盖待审/接受/拒绝、撤回、同ID跨书、默认脱敏、分页；前端覆盖首次静默、增量聚合与切故事；真实HTTP假模型验证后台完成提示、历史前后详情、进入原书及撤回失效。之后回归、构建、发布、附件核对。真实模型语义质量不在本轮保证范围。

## 实施记录

只读投影worldbook_activity、独立API、轻提示与历史面板分别负责自己的边界；旧assetStore重复提示已移除。详情按需请求，未改变模型提示词。文件标识file_id与资产来源标识分开，原书审阅显式by_id，旧显示名路由兼容。

977项Python全量和151项前端通过；补原书文件标识修复与同名不同文件测试后，82项世界书专项通过。3项Edge（记录/修订/多书归属）27.3秒通过，截图已检查。首次测试的搜索框定位文本有误，修正后发现自动书的文件名与显示名不同导致旧审阅入口失败，已修复并通过整流程。当前dev.29构建发布中，未到附件验证完成。
