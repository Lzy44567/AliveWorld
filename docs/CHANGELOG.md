## 设计更新：回合重演与时间线分支 - 2026-08-18

- 将“撤回”“原样回放”“微调重演”“重新推演”和“长期分支”拆成不同操作，避免一个按钮同时承担纠错、读档与随机重抽。
- 原样回放复用已缓存结果，才能保证完全一致；微调重演锁定旧候选与已选未来，只把撤回内容作为一次性 `replay_capsule` 参考，目标是高度相似而非伪造确定性。
- 撤回内容不按固定回合数过期：完整尝试以 `AttemptArchive` 随存档保存，多次尝试可在以后回到相同节点时重新选作参考；真正发给模型的仍是有预算的一次性胶囊。
- 废弃尝试只为偏好系统提供“玩家撤回和修改了什么”的非正式行为证据，不把已经撤销的剧情当成玩家经历或世界事实。
- 时间线节点需要覆盖正文、状态、世界时间、实体、暗流因果账本、记忆与异步任务；全局资产与 API 配置不随故事回退。
- 不把现有“最多 20 份完整深拷贝快照”直接扩成无限历史；后续采用不可变节点、周期检查点与增量状态，分支共享分叉前历史。
- 首个实现切片先修正玩家代理权与回合裁定记录，再做最近一回合微调重演；任意节点、持久化分支和复杂可视化后置。
