## 当前板块的完成定义

1. 持续效果的程序结算和失败恢复已有测试，模型时间/后果质量单独记录并有限修正；不要求无限抽样完美才允许编码NPC。
2. 角色从临时称呼改成名字保持同一身份且仅一张侧栏卡；明确离场不被回忆重新激活，再次在场沿用身份。
3. 同名冲突或错误引用不静默合并；新旧协议兼容，正常/重生成/存取/撤回保持一致。
4. 复用侧栏展示，加入仅测试用稳定选择属性，不添加玩家必填ID或新的管理页面。
5. 单元、假模型真HTTP、浏览器及截图验证；更新设计、分类日志、本地提交。局内数据不外传。

工程组织：身份与更新输入边界由独立npc_identity模块拥有；NpcPresenceTracker处理当前场景展示，StateManager协调副本与metadata；请求构建器负责提示词，GameSession仅接线。无新模型调用，无额外数据库，无完整实体引擎改造。

B实现补充：新协议中的明确在场优先于旧词串启发式；明确离場/显式侧栏删除记录隐藏状态，普通旧更新或名字提及不自动复活，模型需给present=true。名称冲突整回合失败并显示具体说明。同回合身份变更时禁止用status_deletions指向相关NPC，避免旧名误删/跨组误删，应使用present=false。
