# AliveWorld v1.5.0-dev.21-a

这是面向测试玩家的 Windows 便携预发布版。本节点重点修正正文 AI 对玩家行动权、未知事实与外部结果的处理，减少替玩家作决定、把“没有找到”误判成“绝对不存在”等体验问题。

## 本轮更新

- 明确玩家行动权：正文 AI 不应替玩家决定关键行动、态度、承诺或内心结论。
- 区分“世界尚未证实”与“事实不存在”：搜索失败、证据不足或 NPC 不相信，不再自动覆盖玩家声明。
- 新增结构化行动裁定结果，并复用正文同一次模型回复，不额外增加一次 LLM 请求。
- 收紧外部结果边界：AI 可以描述世界反应，但应把关键选择权留给玩家。
- 偏好证据保留玩家原始表达，方便后续偏好分析追溯判断依据。
- 修正括号内补充说明与角色扮演行动之间的识别规则。
- 对齐程序窗口、设置页与前端包的版本号为 `1.5.0-dev.21-a`。

## 更新与使用

- 已运行 `v1.5.0-dev.20` 或更高版本的便携包，可在“设置 → 关于与更新”中测试一键更新。
- `v1.5.0-dev.19` 尚未内置独立更新助手，需要手动下载本版并覆盖程序文件；请保留原有 `UserData` 目录。
- 解压整个 ZIP 后运行 `AliveWorld.exe`，不要只单独复制 EXE。
- 玩家资产、故事、密钥与配置保存在程序目录的 `UserData` 中；覆盖更新前仍建议备份该目录。
- 这是预发布测试版，不会伪装成正式稳定版。
