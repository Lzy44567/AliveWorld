# AliveWorld v1.5.0-dev.19

这是面向测试玩家的 Windows 便携测试版。本轮重点不是扩充玩法，而是把高价值玩家循环纳入自动验收，降低后续更新破坏既有功能的风险。

## 本轮更新

- 新增隔离的假 ComfyUI 测试服务，不消耗真实生图额度即可验证连接、模型发现、任务提交、失败、重试、图片下载和取消。
- 自动验收正文“同一行动重试”和“撤回到上一状态”，避免网络失败后出现重复保存或状态错位。
- 自动验收世界书工坊的草稿隔离、发布和重新进入同步，未发布内容不会污染正式世界书。
- 自动验收生图首次失败后保留任务卡，并可在玩家端重试成功。
- 自动验收页面重载后的故事、局内资产、正文和图片任务恢复。
- 补充稳定的界面测试标识，不改变玩家可见布局和业务协议。

## 使用提示

- 解压整个 ZIP 后运行 `AliveWorld.exe`，不要只单独复制 EXE。
- 玩家资产、故事、密钥与配置保存在程序目录的 `UserData` 中；覆盖更新前建议备份该目录。
- 这是预发布测试版，遇到问题请保留 `UserData/logs` 中对应时间的日志，并在反馈时说明操作步骤。
