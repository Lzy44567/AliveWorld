# AliveWorld v1.6.0-dev.11

这是工作区连续性、后台并发和开发者提示词工具的预发行测试版。

## 主要更新

### 多故事与工坊并发

- 不同故事可以同时等待模型；切换故事不会中止请求，结果和错误只返回原故事。
- 不同工坊对象可以独立处理任务，并保留各自的草稿、对话和状态。
- 同一故事的写操作仍会串行保护，避免两个请求互相覆盖存档。

### 提示词开发工具

- 设置新增受密码保护的开发者模式和提示词工作台。
- 首批正文未来、结算、玩家行动权和连续性切片可以创建本地覆盖并恢复官方基线。
- 未迁移的提示词会明确显示为只读，不会伪装成已经支持编辑。

### 导航与阅读体验

- 世界书、角色卡、文风卡和实体卡回到游戏右侧栏；资源库保留图片与世界包。
- 正文、工坊和日志打开时直接显示最新内容。
- 普通正文气泡移除复制按钮，但仍可直接拖选文字。
- 日志支持拖选、逐条复制/导出及多条批量导出。

### 工坊记录

- 工坊发布后，对话会作为只读历史保存在本机。
- 重启游戏仍可回看；继续创作时建立新的独立草稿。

## 更新方式

可在旧版内使用一键更新。手动更新时，请关闭 AliveWorld，将压缩包里的 `AliveWorld` 文件夹覆盖到原目录；不要删除原目录中的 `UserData`。更新前仍建议备份 `UserData`。

这是预发行测试版。新并发能力受 API 服务商自身并发数、RPM 和网络状态限制；程序只保证不同故事/工坊的状态不会互相覆盖。
